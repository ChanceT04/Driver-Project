# Decision records

Use this folder for choices that affect architecture, data contracts, dependencies, or experiment design. Record the decision after evidence is reviewed; keep tentative ideas in `docs/project-state.md` under open questions.

## Record template

```markdown
# DNNN: Short decision title

- Status: proposed | accepted | superseded
- Date: YYYY-MM-DD
- Evidence: user input, measurements, or linked sources

## Decision
What we chose and the scope it applies to.

## Reason
The evidence and tradeoffs that support it.

## Revisit when
What new evidence or project change would justify changing the choice.
```

Do not record guesses as accepted decisions. When a decision changes, mark the old record superseded and link the replacement; preserve the history.
